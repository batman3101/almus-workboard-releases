# ALMUS WorkBoard 설치 파일

ALMUS WorkBoard의 설치 파일만 두는 저장소입니다(소스 코드는 없습니다).

**최신 버전 받기: [Releases → Latest](https://github.com/batman3101/almus-workboard-releases/releases/latest)**

| 파일 | 대상 |
|---|---|
| `ALMUS-WorkBoard-Setup-<버전>.exe` | Windows 10/11 (64비트) 데스크톱 앱 |
| `ALMUS-WorkBoard-<버전>.apk` | Android 7.0 이상 휴대폰 앱 |

`latest.yml`과 `.blockmap` 파일은 데스크톱 앱의 자동 업데이트가 읽는 파일입니다(받지 않아도 됩니다).

## Windows 데스크톱 앱
- 설치 파일을 두 번 누르면 설치되고 바로 실행됩니다(관리자 권한 필요 없음).
- "Windows의 PC 보호" 창이 뜨면 "추가 정보" → "실행"을 누르세요.
- 회사 이메일과 비밀번호로 로그인합니다. 메신저·할 일·캘린더·공지는 앱 안에서, 문서·보드·워크스페이스는 브라우저에서 열립니다(처음 한 번 "○○ 님으로 계속").
- 설치한 뒤에는 새 버전이 나오면 앱이 스스로 내려받아 알려 줍니다. 알림을 누르거나 앱을 끝낼 때 설치됩니다.

## Android 휴대폰 앱
- APK를 휴대폰에서 열어 설치합니다("출처를 알 수 없는 앱" 허용을 물으면 허용).
- 새 버전은 같은 방법으로 받아 설치하면 업데이트됩니다(데이터 유지).
- 휴대폰 앱은 메신저·할 일·캘린더·공지만 보입니다. 문서·보드·워크스페이스는 PC에서 이용하세요.

## iPhone
아직 앱이 없습니다. Safari에서 https://almusworkboard.com 을 쓰세요.

# Tệp cài đặt ALMUS WorkBoard (Tiếng Việt)

**Tải bản mới nhất: [Releases → Latest](https://github.com/batman3101/almus-workboard-releases/releases/latest)**

- **Windows**: nhấp đúp tệp `.exe` để cài (không cần quyền quản trị). Nếu thấy "Windows đã bảo vệ PC của bạn", chọn "Thông tin thêm" → "Vẫn chạy". Sau khi cài, ứng dụng tự tải bản mới và thông báo; bản cập nhật được cài khi bạn nhấn thông báo hoặc khi thoát ứng dụng.
- **Android**: mở tệp `.apk` trên điện thoại để cài (cho phép "ứng dụng không rõ nguồn gốc" nếu được hỏi). Cài bản mới theo cùng cách để cập nhật.
- **iPhone**: chưa có ứng dụng, hãy dùng Safari với https://almusworkboard.com.
